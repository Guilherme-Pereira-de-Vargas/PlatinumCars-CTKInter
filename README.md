# Platinum Cars

Sistema de gestão de revenda de veículos desenvolvido em Python, com interface gráfica em CustomTkinter e armazenamento em MySQL. Centraliza o gerenciamento de clientes, vendedores, estoque de veículos e vendas.

A interface oferece operações de cadastro, pesquisa, atualização e exclusão de registros. As vendas relacionam cliente, vendedor e veículo, com informações de preço, data e forma de pagamento.
